Main app route

What this route is for

  • Frontend path intended to evolve with the backend
  • Separate from the stable prototype route
  • Safe place to test integration work
  • Can point at a hosted Mongo-backed API later

Important constraint

GitHub Pages is frontend only

  • Pages can host this app route
  • Pages cannot host Node.js or MongoDB
  • Swagger can still be published as static docs
  • The API will need a separate runtime later
