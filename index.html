What to check before you ship

  1. Task capture: add, toggle, and delete flows feel instant and save correctly.
  2. Analytics: discipline score, weekly average, and quadrant counts match the visible tasks.
  3. Responsive layout: notebook cards stack cleanly on small screens.
  4. Data safety: reset is intentional and localStorage migration stays stable.
  5. Docs and deploy: README instructions match the actual repo and GitHub Pages setup.
